# 版本历史

该 Git 历史为项目答辩前按开发阶段整理出的版本记录，用于展示项目功能逐步完善的过程。不要将其理解为真实原始开发历史。

## v1-basic-map-player

基础版本，实现地图显示、孙悟空移动、边界和基础摄像机。

主要功能：

- 加载 `resource/tmx/village1.tmx` 村庄地图。
- 显示孙悟空角色。
- 使用方向键控制移动。
- 摄像机跟随玩家。
- 玩家不能走出地图边界。
- 保留 obstacle 障碍物碰撞。

## v2-maps-npc-dialogue

中间版本，实现多地图/多场景、NPC 加载、NPC 对话和场景切换。

主要功能：

- 支持村庄和寺庙地图。
- 从村庄对象层加载土地公、老人、孩童 NPC。
- 使用对话框显示 NPC 名字和文字。
- 靠近 NPC 后按 `E` 或空格交互。
- 与土地公对话后可以切换到寺庙。
- 不包含怪物战斗、音效和完整开始界面。

## v3-final-playable-demo

最终版本，实现开始界面、UI、音效、怪物、战斗、动画、胜利失败和完整可演示流程。

主要功能：

- 开始界面、操作说明界面和暂停界面。
- 村庄、郊外、寺庙多场景流程。
- NPC 对话、任务推进和回村复命。
- 怪物、Boss、怪物动画、死亡动画和消失特效。
- 回合制战斗系统、孙悟空 `swk2` 攻击动画和命中特效。
- 背景音乐、攻击音效、胜利音效和静音控制。
- 胜利界面、失败界面、重新挑战和最终完成提示。
